WANDER - Stories Beyond The Map
==============================

Is ZIP me tumhari poori website hai. Sirf 1 file hai - index.html - isme sari images bhi andar hi hain, alag folder ki zaroorat nahi.

HOSTING KARNE KA TAREEQA:

OPTION 1 - NETLIFY DROP (Sab se Easy - 2 Minute):
1. Netlify.com/drop kholo
2. Is ZIP ko wahan drag-drop kar do (ya pehle unzip kar ke index.html drop karo)
3. Tumhe live link mil jayega, jaise wander-xyz.netlify.app
4. Site Settings me ja ke naam change kar sakte ho

OPTION 2 - GITHUB PAGES (Free):
1. GitHub.com pe naya repo banao
2. index.html upload karo
3. Settings > Pages > Deploy from main branch select karo
4. Live link: tumhara-naam.github.io/repo-naam

OPTION 3 - HOSTINGER / cPANEL:
1. cPanel > File Manager > public_html kholo
2. index.html wahan upload karo
3. Tumhara domain kholte hi site live hogi

NOTE:
- Ye site static hai, is liye contact form / newsletter pe success message dikhega lekin data database me save nahi hoga. Animations, slider, gallery, dark mode sab 100% kaam karenge.
- Mobile + Desktop dono pe responsive hai.
